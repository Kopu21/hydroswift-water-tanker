# HydroSwift Water Tanker Supply Service

A modern, responsive, high-performance web application designed for on-demand residential, commercial, and industrial water tanker logistics.

## 🚀 Live Testing & Navigation

Open `index.html` directly in any web browser, or serve it using any local HTTP server:
```bash
# Using Python
python -m http.server 3000

# Using Node.js npx
npx serve .
```

---

## 🌟 Key Features & Requirements Covered

### 1. Navigation & Header Controls
- **Home with Sub-Navigation**:
  - **Home 1 (Rapid Residential & Emergency Supply)**: Domestic sumps, drinking RO+UV purified water, high-pressure rooftop pumping, family size volume calculator, 45-minute urgent dispatch.
  - **Home 2 (Industrial & Bulk Logistics)**: Mega 20,000L multi-axle tankers, concrete batching plants, cooling tower boiler feed, civil construction compaction, satellite GPS IoT telematics.
- **Services**: 6 specialized solutions (Potable Drinking Water, Construction Civil Water, Swimming Pool Filling, Event Bulk Supply, Demineralized DM Water, Fire & Drought Emergency Bowsers).
- **Rate Chart**: Interactive pricing calculator based on water grade, tanker capacity (1,000L to 20,000L), distance slider (1 to 50 km), and urgency slot, plus master matrix and monthly retainer plans.
- **Customer Dashboard**:
  - Live GPS Delivery Tracker with step-by-step progress timeline, interactive simulation button (`⚡ Simulate Driver Progress`), moving tanker marker, vehicle speed & telemetry HUD, and driver contact card.
  - New Tanker Booking Wizard with real-time price updates.
  - Order History & Water Logs with instant CSV export.
  - Customer Invoices & Billing with certified tax invoices and printable PDF receipt viewer.
- **Fleet & Quality Lab**: Surgical AISI 304 food-grade stainless tankers, 14-parameter laboratory analysis report, and vehicle lineup.
- **Customer Login Portal**: Multi-role login, account registration, and 1-Click Demo Login (Residential, Industrial, Resort Facility).
- **Contact & Depot Network**: 24/7 hotline, 4 regional dispatch hubs, instant callback form, and interactive FAQ accordion.
- **Header Actions**:
  - **RTL / LTR Toggle**: Real-time layout flipping with mirror styling and Arabic/English font adaptation.
  - **Dark / Light Theme Toggle**: Seamless transition with custom palette persistence.
  - **Customer Login Status Button**: Direct access to portal with user badge.
  - **"Book a Tanker" CTA**: Global modal popup accessible from any page.

### 2. High-Definition Imagery
- **Zero Duplicates**: Exactly 25 curated, high-definition Unsplash images used across all 8 page views with zero image repetition.

### 3. Layout & Alignment
- Responsive CSS Grid and Flexbox with zero horizontal overflow (`overflow-x: hidden`).
- Tested across desktop, tablet, and mobile viewport sizes.
